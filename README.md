# Rapido Fast Auto Clicker (100% Free Open Source)

வீடியோ பார்த்துக் கொண்டிருக்கும் போதும், வாட்ஸ்அப்பில் இருக்கும் போதும் Rapido கேப்டன் ஆப்பில் இந்திய குறியீடு (₹) அல்லது Accept ஆர்டர் வந்த உடனே நொடியில் கிளிக் செய்து ஏற்கும் எளிய ஆப்.

## சிறப்பம்சங்கள்:
1. **எந்த கட்டணமும் இல்லை (Zero Subscription / Paywall)**
2. **நேரடி ஆன்/ஆஃப் சுவிட்ச் (Simple ON/OFF Master Switch)**
3. **மிதக்கும் சுவிட்ச் (Floating Switch)**: வீடியோ மீது மிதந்து கொண்டிருக்கும், அங்கேயே ON/OFF செய்து கொள்ளலாம்.
4. **குறைந்தபட்ச கட்டண வடிகட்டி (Optional Min Fare Filter)**: 0 என வைத்தால் எல்லா ஆர்டரையும் ஏற்கும்.
